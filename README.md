# إعصار أحمد — نسخة مجانية أولية

## تشغيل محلي
```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS/Linux
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

## نشر مجاني على Streamlit Community Cloud
لا يمكن إنشاء رابط مستضاف تلقائيًا دون حساب GitHub وتفويض النشر من مالك الحساب. الخطوات:
1. ارفع ملفات هذا المجلد إلى مستودع GitHub جديد.
2. افتح https://share.streamlit.io/
3. اختر Create app، وحدد المستودع وملف `app.py`.
4. اضغط Deploy. سيُنشأ رابط `*.streamlit.app`.

## ما هو مجاني هنا؟
- الاستضافة التجريبية عبر Streamlit Community Cloud.
- قائمة رموز ناسداك من Nasdaq Trader.
- جلب البيانات عبر مكتبة yfinance/Yahoo Finance، مع ملاحظة أن التغطية والتأخير والحدود ليست ضمانًا تعاقديًا لبيانات السوق.

## قيود مهمة
- قائمة السعودية في النسخة الافتراضية عينة وليست قائمة شاملة لتاسي ونمو؛ ارفع CSV بقائمة الرموز التي تريد فحصها. صيغة CSV: `symbol,market`، حيث market هو `SAUDI` أو `US`.
- الفحص المجاني لآلاف الرموز على خمسة فواصل غير مضمون أن يكتمل بسبب حدود المزود والوقت والذاكرة. اضبط حد الرموز أولًا ثم زد تدريجيًا.
- الفحص يبدأ عند الضغط على الزر، وليس خدمة خلفية دائمة. الاستضافة المجانية قد تنام.
- لا تستخدم هذا النموذج كبيانات لحظية مؤكدة أو لاتخاذ قرارات آلية قبل التحقق من التغطية ومطابقة الإشارات مع TradingView.
- منطق المؤشر محوّل إلى Python، لكن يجب اختبار مطابقة ATR/RMA وHeikin Ashi والشموع المكتملة على رموز وفواصل فعلية قبل الاعتماد عليه.
